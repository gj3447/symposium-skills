# TPA validation checklist

- [ ] Target revision, scope, exclusions, and denominators are exact.
- [ ] Parser/AST tools and versions are recorded.
- [ ] In-scope symbols are recovered, excluded, or explicitly unknown.
- [ ] Contracts cite code and distinguish explicit/conventional.
- [ ] Pattern claims list counterevidence and alternatives.
- [ ] Anchor/binding output remains a proposal until authorized.
- [ ] Drift observations show evidence and impact, not only counts.
- [ ] Partial failures and dissent remain visible.
- [ ] Persistence is local or qualified `PENDING`.
- [ ] No automatic status, Lesson, ActionPlan, research, or recursion occurred.
