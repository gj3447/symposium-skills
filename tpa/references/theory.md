# TPA methodological grounding

TPA is abductive reverse engineering: code observations constrain candidate contracts and architectural
explanations. The output is a best-evidenced recovery model, not proof of the original author's intent.

The method separates inventory, contract inference, pattern inference, and anchor proposal so uncertainty
does not disappear between layers. Round-trip realization, formal methods, or external review can provide
additional evidence when applicable, but no analogy or reviewer count automatically validates the model.

Local recovery is distinct from canonical ratification. Historical every-gate adversarial/KG rules are not
active methodology.
