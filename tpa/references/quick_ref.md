# TPA quick reference

```text
freeze code/revision/scope
  -> TCW inventory
  -> ST contracts
  -> SP patterns + alternatives
  -> TA anchor/binding proposal + drift
  -> local recovery bundle or qualified PENDING proposal
```

- Parser/AST evidence before grep-only structure claims.
- Explicit contracts stay distinct from convention.
- Pattern confidence follows evidence, not thresholds alone.
- Drift denominator is frozen before measurement.
- Counts are telemetry, not verdicts.
- No automatic persistence, research, Lesson, status, or recursion.
