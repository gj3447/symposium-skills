# Prometheus phases

This expands the bounded workflow in [`../SKILL.md`](../SKILL.md). The main skill is authoritative.

## Phase 0 — freeze

Fix the question, decision, scope, evidence bar, source policy, budget, and stop condition before collection.
Scientific work also fixes the highest applicable T0/T1/T2 tier before observing results.

## Phase 1 — prefetch

Read relevant local canon, code, prior receipts, and available KG context. Access is read-only. Capture
paths, revisions, query text, and source dates. Missing context becomes an uncertainty, not a write trigger.

## Phase 2 — plan axes

Choose genuinely distinct concerns and evidence sources. `N` is a maximum coverage budget. Use fewer axes
when the question does not justify more. Define each task's scope, provenance requirement, and stop rule.

## Phase 3 — collect

Dispatch independent read-only work through the parent when useful. Each result separates observation,
inference, evidence lineage, limitations, and dissent. Invalid or late output remains partial/failed.

## Phase 4 — reconcile

Deduplicate shared evidence, preserve contradictions, and assess directness, quality, applicability, and
independence. Do not vote by finding or agent count.

## Phase 5 — synthesize

Return the narrowest supported answer, decision impact, unknowns, and bounded follow-up candidates. A
discovery does not automatically reopen the cycle.

## Phase 6 — handoff

Act only when the original task authorizes it. Otherwise return a local report. Material reusable evidence
may become a `PENDING` proposal; canonical mutation is a separate ratified operation.
