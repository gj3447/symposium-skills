# Prometheus validation

Validate in proportion to the decision:

1. source identifiers, dates, revisions, and quotations resolve;
2. critical observations can be reproduced or independently checked when feasible;
3. structured findings contain evidence, limitations, and dependence groups;
4. shared-source duplicates are not treated as independent corroboration;
5. contradictions and singleton counterevidence remain in the synthesis;
6. the conclusion does not exceed the frozen evidence bar;
7. implementation claims include directly relevant tests or exact external readback;
8. persistence is local or `PENDING`, never an unratified canonical mutation.

Report commands and observed outcomes exactly. A producer's return value is not independent proof of an
external effect.
