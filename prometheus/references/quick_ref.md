# Prometheus quick reference

```text
freeze question/scope/bar/budget
  -> read existing context and primary sources
  -> plan genuinely independent axes
  -> collect structured findings
  -> deduplicate by evidence lineage
  -> preserve conflict and uncertainty
  -> synthesize the narrowest answer
  -> local handoff or qualified PENDING proposal
```

- `N` = maximum coverage budget, never a vote.
- Default permissions = read-only.
- Same-data rerun = reproduction, not independent evidence.
- Discovery = bounded follow-up candidate, not automatic recursion.
- Ordinary result = local artifact.
- Canonical mutation = separate authorized ratification.
