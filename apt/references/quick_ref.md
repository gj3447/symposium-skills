# APT quick reference

```text
freeze objective/scope/authority
  -> route from actual artifact state
  -> SA meaning
  -> SP decomposition
  -> ST contract
  -> SCW implementation + evidence
  -> proportional cleanup
  -> optional MetaReview only for reusable method impact
```

- Apply only relevant gates.
- Use formal critics only when risk warrants them.
- One supported blocker may block; counts never approve.
- Ordinary artifacts and receipts stay local.
- Canonical mutation needs identified `PENDING` evidence and separate ratification.
- Discovery and method review never recurse automatically.
