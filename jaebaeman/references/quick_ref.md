# Jaebaeman quick reference

```text
pre-fetch shared context
  -> plan independent bounded TaskSpecs
  -> dispatch with explicit permissions and limits
  -> collect schema-valid evidence
  -> classify partial/failure honestly
  -> integrate without count-voting
  -> local manifest or qualified PENDING proposal
```

- Default child permission: read-only.
- One task: one bounded deliverable.
- Current runtime schema wins over historical examples.
- Retries, concurrency, waits, and descendants are bounded.
- No automatic sibling, fractal seed, status write, or recursion.
