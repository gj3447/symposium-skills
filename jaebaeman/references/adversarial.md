# Jaebaeman adversarial checks

Before dispatch, ask:

- Are the tasks actually independent, or is parallelism performative?
- Could two agents edit the same path or external record?
- Is any child receiving broader authority or context than needed?
- Are outputs independently testable, or merely opinions to be counted?
- Is there a bounded cancellation and timeout path?
- Could the parent mistake partial completion for full coverage?
- Does a requested retry risk duplicating an external effect?

After collection, preserve one evidence-backed blocker even if other agents report success. Duplicate or
shared-input reports remain one evidence lineage. A finding count is never a quality score.
